# O que você aprenderá neste curso

Neste curso, você aprenderá a:

* **Identificar demandas de rede e produtos relevantes do Google Cloud** em cada etapa do pipeline de IA.
* **Descrever padrões e componentes de arquitetura de rede** para IA.
* **Diferenciar os recursos de rede** para diferentes tipos de máquinas com GPU.
* **Identificar opções de rede** para ingestão de dados, treinamento de IA e inferência de IA generativa.
* **Reconhecer as melhores práticas de rede** para IA.
